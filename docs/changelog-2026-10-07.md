# 2026-10-07 修改紀錄

本次修改的重點、改到的檔案，以及到另一台電腦接手時要做的事。

## 一、管理者可代記、可更換記帳者

**規則**

- 新增交易：記帳者預設是登入者。管理者可指定其他成員（代記）；一般成員指定他人回 403。
- 修改交易：管理者可更換記帳者，會寫一筆 revision（欄位 `payerId`）；一般成員不行。
- 不可指定已停用的成員（回 400）。原記帳者已停用、但沒改記帳者時不擋。
- 訂閱產生的交易不可換記帳者（要換請改訂閱的扣款人）。
- 個人帳交易不可換記帳者（`owner_id` 必須等於 `payer_id`）。

**新增「建立者」欄位 `created_by`**

- 記錄實際輸入的人；`null` 代表系統自動產生（Cron 訂閱扣款、強制匯入）。
- 手動「標記已扣款」記為按下的管理者。
- 交易的 API 回應多了 `createdBy`、`createdByName`；編輯視窗在代記時顯示「由 X 代記」。

**資料庫異動** `api/sql/0003_transaction_created_by.sql`（可重複執行）

- 新增 `transactions.created_by`；舊的手動交易回填為 `payer_id`。
- `transaction_revisions` 的欄位白名單加入 `payerId`。

## 二、年度彙整頁

- **分類生命週期外的交易不再被藏起來**：例如「教育」設定 8 月新增，5、7 月的實際交易原本不顯示，也沒算進支出合計。現在只要有交易就顯示、就算進合計；首頁的分類卡片也一樣。
- **底部合計列**：依序為「收入合計 → 支出合計 → 月結餘」。結餘為負時顯示紅字。
- **月結餘列的年度總計＝年度結餘**：全年收入 −（支出合計年度總計，含年度額外開銷）；「額外開銷」欄以負數列出。
- **頂端「結餘」卡片**改為年度結餘，備註「包含年度額外開銷 N」。（「全年支出」卡片仍不含額外開銷。）
- **手機版**多一張「月結餘」卡片。
- **拿掉「成員年度花費」**：前後端都移除 `byMember`；要看成員花費請用統計圖表頁的成員篩選。
- 年度彙整 API 新增 `monthly`（12 欄，每月收入、支出、結餘，不含年度額外開銷）。

## 三、2026 年 1～9 月強制匯入正式資料庫

程式：`api/src/db/force-import-2026.ts`

```bash
cd api && pnpm db:force-import-2026            # 只試算，不寫入
cd api && pnpm db:force-import-2026 --apply    # 真的執行
```

執行時（同一個 DB transaction，失敗整批還原）：

1. 要清除的資料先備份到 `api/backups/*.json`（已加入 `.gitignore`）。
2. 軟刪除家庭帳 2026-01-01～09-30 的全部交易（含訂閱產生的）。
3. 刪除 2026 年的年度額外開銷（此表無軟刪除，靠第 1 步備份）。
4. 塞入試算表資料：每個項目每月一筆，日期為該月最後一天，金額 0 略過。

- 記帳者一律是成員「系統」（帳號 `system`、停用、無密碼、不能登入；不存在會自動建立）。
- `created_by` 為 null；備註格式「食（系統匯入）」。
- 可重複執行，結果相同。10 月以後、個人帳、其他年度的資料不受影響。

**分類對應**：薪資1、薪資2 →薪資／本薪；其它收入 →薪資（無子分類）；食→食、健康→健康、育→教育、樂→育樂、網路→訂閱。

**年度額外開銷**：健檢 9,900（健康）。

## 五、到另一台電腦接手

1. 安裝套件並先編譯共用套件（`shared/dist` 不進版控，沒編譯的話測試會失敗）：
   ```bash
   pnpm install
   ```
   ```bash
   pnpm --filter @family-ledger/shared build
   ```
2. 建立 `api/.env`（從 `api/.env.example` 複製），填入正式的 `DATABASE_URL`、`JWT_SECRET`。
3. 套用資料庫異動：
   ```bash
   cd api && pnpm db:push
   ```
4. 先試算，確認要清除的筆數與金額是預期的舊資料：
   ```bash
   cd api && pnpm db:force-import-2026
   ```
5. 沒問題再執行：
   ```bash
   cd api && pnpm db:force-import-2026 --apply
   ```
6. 到分類設定頁確認「健康」沒有被停用；若停用，按「重新啟用」。
7. 部署新版程式。
